# Spec — Petrel v1 补完

> 视觉部分（视觉真相源、颜色 token、字体、图标、导航结构）已由 `docs/spec/skins.md` 取代；本文的产品决定、行为细节与「画稿没画到的部分」中的行为条目仍然有效，除非 `skins.md` 另有规定。

原型（`av:dllg404i`）证明了架构在真机上成立。本文件是把 AGENTS.md「v1 功能范围」补齐的共用真相源：任务怎么拆、界面长什么样、已经定下的产品决定。每条任务的行为细节写在各自的 anvil task prompt 里，这里只放几条任务共用的部分。

## 任务拆分与顺序

anvil 主题 `petrel:v1`，按下面的顺序做。后一条可能用到前一条的产物，各条 prompt 写明了依赖。

| # | 任务 | 内容 | 画板 |
|---|---|---|---|
| 1 | 补齐常驻与系统入口 | 最近任务卡片、始终开启 / 开机拉起、被别的 VPN 顶掉时同步状态、常驻通知改版 | `System` |
| 2 | 做节点操控与主界面 | 三标签导航骨架、首页（含链路图）、节点页（所有 select 组、切换、测延迟）、通知补出口、secret 兜底 | `Main`、`HomeEmpty`、`Nodes` |
| 3 | 做 tailnet 面板 | 本机状态、节点列表（直连 / 中继 / 空闲 / 离线）、登出、待登录页 | `Tailnet`、`TailnetLogin` |
| 4 | 做配置导入 | 系统文件选择器导入 YAML、先校验再替换、运行中自动重启、App 内替换 GeoIP 库 | `Config`、`ConfigError`、`HomeEmpty` 的导入按钮 |

## 视觉真相源

画稿是视觉的唯一真相源：字号、颜色 token、图标、控件位置与排列、间距、各状态的样子都以画稿为准。task prompt 只规定行为、数据、交互逻辑，以及画稿没画到的部分。

- **画稿源**：`docs/spec/assets/ui-v1/src/<画板>.dc.html`。每个元素的尺寸、间距、圆角、字号都写在 inline `style` 里，要取精确数值就读源文件。
- **渲染图**：`docs/spec/assets/ui-v1/png/<画板>-light.png` 与 `<画板>-dark.png`，按 390 dp 宽、2 倍密度渲染（PNG 宽 780 px）。用 Read 工具直接看图。
- **在线画布**：https://claude.ai/artifact/PcPiN6ZBu43B9N5pA7KeBE（需要人的 claude.ai 登录）。仓库里的副本与画布一致；画布以后若有改动，以人另外指明的版本为准。
- 画稿里的 IP（`100.64.0.x`）、延迟数值、离线节点 `op12`、登录链接都是示意数据，实际内容来自内核。

### 单位换算

画稿的 px 就是 Compose 的 dp，字号 px 就是 sp。画稿没画系统状态栏：顶部留白等于状态栏 inset 加上画稿 header 的 padding（App 走 edge-to-edge）。底部导航栏同理，底部加上手势条 inset。

### 颜色 token

逐字摘自每个画板源文件 `<helmet><style>` 的第 16、17 行（选择器 `.pt` 是亮色，`.pt.dark` 是暗色）：

```css
.pt{--bg:#F2F5F6;--surface:#FFFFFF;--surface-2:#E7ECEE;--ink:#11181C;--ink-2:#4A5761;--line:#D2DADE;--accent:#0C6A76;--on-accent:#FFFFFF;--accent-soft:#D3EBEE;--ok:#1B7346;--warn:#985200;--warn-soft:#F8E8D2;--err:#B3261E;--err-soft:#FBE2DF}
.pt.dark{--bg:#0C1114;--surface:#141B1F;--surface-2:#1D262B;--ink:#E4EAED;--ink-2:#9AA8B0;--line:#28333A;--accent:#61C3CF;--on-accent:#05181B;--accent-soft:#11343A;--ok:#5ECA8F;--warn:#E6A64B;--warn-soft:#33261A;--err:#F28B82;--err-soft:#3A1C1A}
```

落地方式（任务 2 建立，之后的任务复用）：

- `app/src/main/java/com/robb3n/petrel/ui/theme/` 下定义 `PetrelColors`，14 个字段与上面的 token 一一对应，亮暗两套，经 `CompositionLocal` 提供。明暗跟随系统（`isSystemInDarkTheme()`），**不用** Material You 动态取色。
- 同时把 token 映射进 Material3 `ColorScheme`，让 M3 组件（NavigationBar、AlertDialog、Button 等）默认就用对颜色：`primary=accent`、`onPrimary=on-accent`、`primaryContainer=accent-soft`、`onPrimaryContainer=accent`、`background=bg`、`surface=surface`、`surfaceVariant` 与 `surfaceContainer*=surface-2`、`onSurface=ink`、`onSurfaceVariant=ink-2`、`outline` 与 `outlineVariant=line`、`error=err`、`errorContainer=err-soft`。
- 状态色的用法：`ok` 表示正常（已连接、直连、低延迟），`warn` 表示需要留意（待登录、中继、高延迟），`err` 表示失败（超时、导入失败），`ink-2` 表示不活跃（未连接、离线、空闲）。状态从不只靠颜色区分，旁边都有文字。

### 字体

- 中文与正文用系统默认字体（`FontFamily.Default`）。**不打包** Noto Sans SC：每个字重都是 10 MB 量级。ColorOS 的系统字体与画稿 Noto Sans SC 的字形差异属于已接受偏差，对照截图时不算问题。
- 等宽数据用打包的 IBM Plex Mono，包括节点名、组名、IP、延迟、文件名和配置键（画稿里 `class="mono"` 的元素）。只打包 Regular 400 和 Medium 500 两个字重，ttf 放 `app/src/main/res/font/`（文件名 `ibm_plex_mono_regular.ttf`、`ibm_plex_mono_medium.ttf`）。字体来源用 `github.com/IBM/plex` 的 release 或 `github.com/google/fonts` 的 `ofl/ibmplexmono/`。许可证是 OFL-1.1，许可文本放 `licenses/IBM-Plex-Mono-OFL.txt`（可以和 GPL-3 的 App 一起分发）。
- 字重：画稿 `font-weight: 700` 对应 `FontWeight.Bold`，`500` 对应 `FontWeight.Medium`。

App 图标、磁贴与常驻通知图标是同一个「合流」标志：两条线汇成一条、末端一个节点，表示 tailnet 与代理装进同一个 VPN。磁贴 / 通知用白色单色的 `res/drawable/ic_tile.xml`（24 网格）；启动器是自适应图标，前景上线奶油色、下线 Shoal `--gold`、端点奶油色，背景为上浅下深的海蓝渐变，另带 monochrome 层供 Android 13+ 主题图标。三处图形要一致，改一处须同步另外两处（`ic_launcher_foreground.xml`、`ic_launcher_monochrome.xml`）。

### 导航结构

- 底部导航三项：连接（首页）、节点、tailnet。条目用 Material3 `NavigationBarItem`，容器自己搭（surface 底加顶部 1 dp `line` 描边，高度 10 + 56 dp 加手势条 inset）：`NavigationBar` 的高度固定 80 dp，对不上画稿。样式对齐画稿：选中项是 64×32 dp 的 `accent-soft` 胶囊，图标用 `accent`，文字用 `ink` 加粗；未选中项的图标和文字都用 `ink-2`。
- 配置是二级页：从首页的「配置」行进入，左上角返回，不显示底部导航。
- 返回键：配置页回首页；在节点或 tailnet 标签上回首页；在首页按返回就退出 Activity。

### 画稿没画到的部分

- 对话框用 Material3 `AlertDialog`，颜色走上面的映射。
- 加载中：数据还没到时，数值位置显示 `—`（`ink-2`），不用骨架屏或转圈。
- 长节点名：与 4 位数延迟同行时宽度不够，在连字符后允许换行（显示文本里插零宽空格），折成两行，不在词中间断开，也不截断。节点卡和首页链路块都这样处理。
- 节点组排序：同配置文件的 `proxy-groups` 顺序（取 `GLOBAL` 组成员的顺序）；不在其中的组排最后，按名字排序。
- 短提示用 `Toast`，文案在各任务里写定。
- tailnet 标签（任务 3 定）：「VPN 未连接」页的判据是 VPN 既不在运行也不在启动（`!active`），启动中走正常布局，免得连接中闪「未连接」；数据没到时节点名、节点列表与在线数显示 `—`，本机 IP 先用 `CoreState.tailnetIPs` 兜底；登录页两个按钮等宽（画稿是按内容比例，差几 dp，已接受）；登出按钮在已登录布局的所有状态下都显示。
- 配置页（任务 4 定）：
  - 导入失败的横幅在配置页显示；从首页 `HomeEmpty` 的按钮发起、失败时自动导航到配置页。横幅一直显示，直到下一次导入开始或离开配置页（明暗切换、旋转屏幕重建 Activity 不算离开）。
  - 错误状态下，说明行、GeoIP 卡片与「改写的部分」卡片照常显示在导入按钮下方（`ConfigError` 画板只画了上半部分）。
  - GeoIP 替换：文件超过 64 MiB 与校验失败同一句 Toast「不是有效的 GeoIP 库」；读取失败「读不了这个文件：…」；保存失败「保存失败：…」。「替换…」校验中显示「校验中…」并禁用；状态未算出时显示 `Country.mmdb · —`。
  - 写入顺序：两个 tmp 写好 sync 后，先 rename `config.yaml`、再 rename meta；meta 这一步失败时配置已换上，删掉旧 meta（界面退回 `config.yaml` 与文件时间），不当作导入失败。
  - 运行中重启期间首页、磁贴会短暂闪一下「未连接」（Go 侧 `Stop()` 会推一次 stopped）。

### 视觉对照（每条带画板的任务的完成判据）

- 用 `adb exec-out screencap -p` 截屏。界面在模拟器 a35 上就能到达的状态在 a35 上截，需要 VPN 运行的状态在真机上截。
- 与 `png/<画板>-light.png`、`png/<画板>-dark.png` 在同明暗面下并排对照（切换明暗用 `adb shell cmd uimode night yes|no`，真机测完恢复人原来的设置）。缩放到同宽后逐项核对：布局与排列、间距、字号层级、颜色 token、图标、各状态文案。
- 偏差要么改到一致，要么列进 check 复述交给人定。字体字形差异（见上文「字体」）不算偏差。

## 产品决定

本主题 refine 时定下的（2026-10-02），forge 不再问：

1. 导航是三标签加配置二级页。
2. 节点页列出配置里**所有**非隐藏的 `select` 组，不只 PROXY。顺序同配置文件。
3. 首页保留「当前链路」图：第一个 select 组当前选中节点的 `dialer-proxy` 链，由 Go 层算出。
4. App 内可以替换 GeoIP 库（`Country.mmdb`）。
5. tailnet 待登录时，常驻通知带「复制登录链接」按钮。
6. 用户配置没写 `secret` 时，注入随机 secret。mihomo 的 REST 接口固定开在 `127.0.0.1:9090`，手机上任何 App 都连得到。
7. 切换节点后，断开链路里经过该组的现有连接，让切换立刻生效。
8. VPN 进入运行状态后，先预热 tailnet 第一跳，再自动给所有 select 组测一次延迟。之后：界面可见时每 30 秒探测各组当前选中的节点（25 秒内测过的跳过），切网后预热并探测一次；其余成员由人手动点「测延迟」。
9. 导入新配置或替换 GeoIP 库时，如果 VPN 正在运行，自动重启 VPN 使其生效。
10. 中文用系统字体，等宽数据打包 IBM Plex Mono（见「字体」）。
